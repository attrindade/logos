# logos — Instruções para Claude

## Second Brain (vault Obsidian)

Este projeto está ligado ao vault pessoal em `C:/Workspace/notes` pelo servidor MCP `om`
(registrado em `.mcp.json`). O vault guarda decisões, armadilhas já encontradas, contexto de
cliente e histórico que **não estão neste repositório**.

**Antes de propor arquitetura, escolher uma abordagem ou repetir uma decisão de design,
consulte o vault.** Use `recall` para lições escopadas a este repo e `search` para o resto.
Se o vault registrar uma abordagem como rejeitada, **não a implemente** — cite a nota e
proponha outra coisa.

Isto não é sugestão. Sem esta seção, uma sessão com o servidor ligado fez zero chamadas ao
vault e implementou um design que o vault registrava como explicitamente rejeitado.

Ao terminar algo cuja lição valha em outro repositório, registre com `remember` (declare o
escopo: `project`, `platform` ou `general`). O que aconteceu só aqui vai em `record_work`.
